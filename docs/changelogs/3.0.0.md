### 🚀 Features

- **Minecraft 26.x support**: Added support for Minecraft 26.1, 26.1.1, and 26.1.2.

### ⚠️ Breaking Changes

- **Forge support dropped**: Forge is not available for Minecraft 26.x. Use the NeoForge build instead.
- **Java 25 required**: Minecraft 26.x+ requires Java 25 at runtime and build time.

### 🔧 Infrastructure

- Switched to `dev.architectury.loom-no-remap` plugin (Minecraft 26.x is unobfuscated, no mappings needed).
- Dropped ParchmentMC mappings — no longer applicable without obfuscation.
- Bumped Architectury plugin to `3.5-SNAPSHOT` and Architectury Loom to `1.14-SNAPSHOT`.
- Updated CI and devcontainer to Java 25.
- Updated Shadow plugin to `com.gradleup.shadow:9.3.0`.
